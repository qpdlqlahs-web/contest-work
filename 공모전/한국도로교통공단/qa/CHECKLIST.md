# 거북이 모드 ON — 제출 전 검수 체크리스트

각 항목은 **측정/증거와 함께** 통과(✅) 또는 실패(❌)로 기록한다. 하나라도 ❌이면 사용자에게 보내지 않는다.

## A. 법규·사실 (도로교통공단 심사 기준)
- [ ] A1 보행신호: 위 빨강(정지) / 아래 초록(보행), 한 번에 하나만 점등. 보행 중에는 초록 유지
- [ ] A2 차량은 정지선 뒤에 정차. 횡단보도 위 정차·통과 없음 (보행신호 초록일 때 차 이동 없음)
- [ ] A3 보호구역 표지: 30 제한속도 + 어린이 + 노인 표지
- [ ] A4 개인형 이동장치(PM): 성인 탑승, 헬멧 착용, 자전거도로 주행
- [ ] A5 아동은 차도에 서 있지 않음 (횡단보도 횡단 제외)
- [ ] A6 단속카메라: 한국 고정식 형태, 플래시가 카메라 장비에서 발광
- [ ] A7 속도계/숫자: 후렴 "삼십" 장면에서 정확히 30
- [ ] A8 자동차 안전띠: 뒷좌석 포함 착용 묘사
- [ ] A9 방향지시등: 회전 전 점등
- [ ] A10 거북이(주인공)차는 위반 행동 없음 / 위반은 토끼차만, 반드시 결과(단속) 제시

## B. 화면
- [ ] B1 글자: 화면 내 깨진 글자·영문·한자 0 (자막·엔딩 제외). 실제 상표·로고 0 (공단 로고 제외)
- [ ] B2 캐릭터 일관성: 할머니·손주·거북이차·토끼차·호둥이 디자인 유지, 얼굴은 앞유리에만
- [ ] B3 움직임: 차량 역주행/후진/순간이동 없음, 도로·배경 미끄러짐 없음, 신체 변형 없음 (6fps 연속 프레임)
- [ ] B4 컷 재사용 0 (모든 컷 1회)
- [ ] B5 컷 전환: 박자 위, 동작 중간 튐 없음, 장면 간 방향성 자연스러움
- [ ] B6 색감 통일 (컷별 평균색 편차 보정)
- [ ] B7 프레임레이트 24fps 일관(저더 없음), 느린 컷은 보간 처리
- [ ] B8 자막: 가사와 시간 일치, 오탈자 없음, 하단 안전영역(숏폼은 UI 영역 회피)

## C. 소리
- [ ] C1 음악 이음부 0 (광고) / 숏폼은 원곡 반복 지점에서만 이음 + 측정값 기록
- [ ] C2 끊김 검출(qa/audio_gaps.py) = 원곡에 없는 끊김 0
- [ ] C3 효과음은 화면 사건과 동기 (셔터 = 플래시 프레임)
- [ ] C4 음량: -16 LUFS(광고) / -14 LUFS(숏폼), 트루피크 ≤ -1 dBTP

## D. 규정
- [ ] D1 광고 90초~3분 / 숏폼 20초~1분, 해상도 1920x1080 / 1080x1920
- [ ] D2 AI 활용 명시 가능, 미발표작
- [ ] D3 음원 상업권(Suno Pro), 폰트 OFL, 공단 CI/캐릭터 공식 제공본
