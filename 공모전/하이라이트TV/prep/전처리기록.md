# 전처리 기록 (10/10) — 「나, 주연」 소스 전처리

- 스크립트: `prep\preprocess.py` (실행: `python prep\preprocess.py stills|clips|all [이름]`), 확인용 `prep\check_stills.py`, `prep\stats.py`
- 원본(`img\`, `clips\`)은 읽기만 했다. 결과는 `prep\stills\`(24장, 1920x1080 PNG), `prep\clips\`(4개, 1920x1080 24fps mp4). 확인 프레임은 `prep\_check\`.
- 정지 컷 순서: lanczos 축소 → 블러/보정(Python) → 색 레시피(ffmpeg). 클립 순서: lanczos 1.5배 업스케일 → 블러/국소 보정(Python) → 색 레시피 + 인코딩(ffmpeg).
- 클립 인코딩: libx264 CRF 12(요구 14 이하), preset slow, yuv420p, 24fps, bt709 태그, 오디오 없음.
- 블러: 가우시안 σ12(명찰은 σ10), 경계 페더 8~14px. 좌표는 지시서 기준(1920x1080).

## 의문점 / 감독 판단 요청
1. **K1 명찰 블러 구간 확대**: 지시는 2.0–2.6s였으나 명찰 무늬가 1.4s(손 아래에서 드러남)부터 2.9s(우산이 가림)까지 계속 보여서 1.45–3.0s로 넓혔다. 2.0–2.6만 원하면 `preprocess.py`의 `t0, t1` 수정 후 재실행.
2. **K2b 커피봉지 블러 추가**: 지시는 K2b에서 명찰만 언급했지만 K2Se(시작 프레임)의 커피봉지 블러 지시가 있고 K2b에도 같은 위치에 라벨이 보여 함께 블러했다. 봉지 주변 컵·주전자 일부도 같이 흐려진다.
3. **C05·C06b 색**: 현실 톤인데 레시피 목록에 없다. 실측 G/R 1.01·0.93, 휘도 102·103으로 이미 휘도 목표 근처여서 `gm=0.02`만 적용하고 밝기 보정은 생략했다.
4. **C18 시간 해석**: 6시 = 시침 아래, 분침 위(6:00)로 해석했다. 두 바늘 모두 아래(6:30 형태)를 원하면 분침 교체가 추가로 필요하다.
5. **색 레시피 결과 수치**: 지시서 레시피를 그대로 적용했고 목표(G/R 0.72, 휘도 100)와는 컷별로 차이가 남는다. 현실 계열(C07·C20·C21·K4Sb)은 G/R이 0.98~0.99로 목표보다 훨씬 높고(회녹색 유지), 휘도는 94~108이다. 드라마 계열은 G/R 0.65~0.81, 휘도 81~142(C19b 142가 가장 밝음). 레시피 값 조정이 필요하면 알려 달라.
6. **K2b 색**: 핑크 캐스트가 줄지만 주인공 머리와 벽이 회녹색 쪽으로 기운다(gm=0.05). 좌측 가장자리의 노랑/핑크 번짐은 남아 있다. K3는 드라마 레시피로 사무실 칸막이가 더 녹색, 전체가 더 밝아졌다.
7. **YUV 행렬**: 원본 클립이 색 태그가 없어 bt709로 해석해 디코드·인코드했다(bt601 가정 시와 차이는 미미).
8. 2752x1536 원본(C02·C03·C05)은 16:9가 아니라 좌우 약 11px씩 잘라 사용했다(블러 좌표는 변환 적용).
