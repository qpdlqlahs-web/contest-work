범위: 정지 컷·클립 전처리만. 최종 편집·자막·음악은 하지 않음. 원본(`img\`, `clips\`)은 수정하지 않음.
스크립트: `prep\stills_prep.py`(정지 컷), `prep\clips_prep.py`(클립), `prep\splash_c08.py`(C08 물보라). 작업용 PNG 시퀀스는 scratchpad에 둠.
출력: `prep\stills\*.png`(1080x1920), `prep\clips\*.mp4`(1080x1920, 24fps, H.264 CRF 12, 오디오 없음, yuv420p). 확인용 jpg는 `prep\_check\`.

## 클립 (720x1280 -> 1080x1920 Lanczos + unsharp 5x5 0.5(루마만), 24fps)
슬로는 minterpolate(mci, aobmc). 끝 구간 보간 누락 방지로 입력 끝 프레임을 3장 복제 후 처리.
| 클립 | 적용 | 결과 |
|---|---|---|
| C01 | in 0.50-3.00s, 1.25배속 | 48f = 2.0s |
| C04 | in 0-2.40s, 0.8배속 -> 72f. 원본 f55(1-based) 위치(출력 f69)를 0.8s(19f) 프리즈 | 91f = 3.79s |
| C08 | in 0-2.625s, 0.75배속 -> 84f + 마지막 프레임 0.3s(7f) 프리즈 + 물보라 합성 | 91f = 3.79s |
| C11 | 0-3.0s 그대로(72f) + 마지막 프레임 0.8s(19f) 프리즈 | 91f = 3.79s |
| C14 | 전체 0.8배속 | 91f = 3.79s |
- 길이 3.8s 목표 대비 0.01s(1프레임의 5분의 1) 짧음. 24fps에서 3.8s=91.2f라 정수 프레임으로 맞춤.

### C08 물보라
- 타이밍: 출력 3.33s 시작, 정점 3.4~3.45s, 3.8s까지. 중심 (430,1780)@1440 = (322,1335)@1080.
- 구성: 물방울 11개(주 8 + 작은 위성 3), 파문 2겹(납작한 타원 링, 흰 하이라이트 + 호박색 그림자), 중앙 물기둥 돔+기둥 5개. 방울은 반투명 호박색 + 흰 하이라이트 + 서브프레임 4샘플 모션 블러(세로로 늘어남). 방울은 감초 발 아래(y1170 이하)에서 멈추게 높이를 제한해 감초와 겹치지 않아 레이어 순서(감초 아래) 문제 없음.
- 크기: 지시서의 폭 360px(@1440) 그대로면 클립 속 탕이 정지 컷보다 작아 폰에서 거의 안 보여 1.4배로 키움(폭 약 500px@1440). 원 지시대로 되돌리려면 `splash_c08.py`의 `SC = 1.0`.
- 감초 반사: 지시서 좌표 (x230-440,y1850-2060)에는 클립 안에서 반사가 없었다(정지 컷 기준 좌표로 보임). 클립의 실제 반사는 약 (x520-720, y1870-2090)@1440이고 파문(y~1780)은 이를 덮지 못함. 그래서 이 위치를 지웠다: 좌우 물 띠의 행별 중앙값(잎·꽃 제외) 가로 보간 85% + σ15 블러 15%, 타원 마스크 페더, 2.9s -> 3.3s에 걸쳐 램프. σ15 블러만으로는 밝은 얼룩이 남아 이 방식으로 바꿈. 램프 구간(2.9-3.3s)에서 반사가 서서히 옅어지는 것이 보임.

## 미처리·보류
- C06의 君 그림자: 왼쪽 그림자는 뾰족한 서양식 왕관 모양이고 오른쪽은 갓. 지시서의 "익선관 실루엣 검토" 결과, 조선 임금의 익선관(둥근 모자 + 양옆 날개)과 모양이 달라 서양 왕관으로 읽힐 수 있음. 정지 컷 자체는 건드리지 않음. 재생성 또는 익선관 모양 그림자 합성이 필요한지 AD 판단 요청.
- C03d는 가짜 글자가 있던 라벨을 빈 라벨로 덮음. 라벨색이 원본 종이보다 약간 단색·분홍빛. 후반에서 질감이 거슬리면 σ2 블러/노이즈를 더할 수 있음.
- 지시서의 C08 "좌측 서랍장 마루색 덮기(선택)"는 클립에서 서랍장이 거의 보이지 않아 하지 않음. 벽 라벨 σ12도 Kling 시작 프레임(_fix)에 이미 적용돼 있어 추가하지 않음.
- C04·C11 클립 하단/좌측의 Kling 시작 프레임 블러(_fix)는 그대로 남아 있음(서랍 라벨 부분이 흰 얼룩처럼 보임). 화면에서 의도된 블러.
- 자막 위치 결정("결정 필요" 항목)은 이 단계 범위가 아니므로 하지 않음.

## 의문점
1. C04 프리즈 "f55(2.25s)"의 기준: 원본 f55(2.29s)로 해석해 출력 약 2.85s 지점에서 프리즈(출력 후반, 끝 구간 약 0.15s는 프리즈 뒤에 이어 재생). 출력 타임라인 2.25s였다면 위치가 달라짐(`clips_prep.py`의 `idx` 한 줄 수정).
2. C14 마지막 0.8s(출력 3.0s 이후): 감초가 카메라 쪽으로 커지며 화면 아래 중앙(y 약 60-90%)을 차지하고 모션 블러가 큼. 지시서의 자막 회피 영역과 일치함. 관람객 일부가 프레임에서 빠짐.
3. C08에서 감초가 탕 가장자리 바깥(마루)에서 뛰고 있어 물에 들어가지 않음. 물보라는 지시대로 합성했으나, 맥락상 "가장자리에서 튀긴 물방울"로 읽힘.
4. C13 배경 블러로 뒤 서랍장 라벨은 흐린 흰 사각형이 남음(글자는 읽히지 않음).
